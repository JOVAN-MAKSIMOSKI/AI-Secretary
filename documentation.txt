GMAIL SETUP (REVERTED FROM SMTP TO GMAIL API)

The email sender now uses Gmail API OAuth (not SMTP).
Required env vars in apps/agent:
- GOOGLE_CLIENT_ID
- GOOGLE_CLIENT_SECRET
- GOOGLE_REDIRECT_URL (optional, defaults to http://localhost:3000/auth/google/gmail/callback)
- GMAIL_TOKEN_ENCRYPTION_KEY (32-byte base64 or 64-char hex)
- GMAIL_OAUTH_STATE_SECRET
- GMAIL_FROM_EMAIL (optional, fallback sender header)

Scopes needed when generating refresh token:
- https://www.googleapis.com/auth/gmail.send
- https://www.googleapis.com/auth/calendar
